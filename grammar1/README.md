# grammar1 — Python の基本文法

番号順に進める。各テーマは「フル写経 → 似たテーマで復習」の対。

| 文法項目 | フル写経 | 復習 |
|----------|----------|------|
| 変数・`print`・f文字列 | `01_variables.py` | `02_variables_review.py` |
| 数値演算（`/` `//` `%` `**`） | `03_numbers.py` | `04_numbers_review.py` |
| 文字列の添字・スライス・メソッド | `05_strings.py` | `06_strings_review.py` |
| 条件分岐 `if / elif / else` | `07_if.py` | `08_if_review.py` |
| 繰り返し `for` / `range` / `enumerate` | `09_for.py` | `10_for_review.py` |
| 関数定義（引数・戻り値・デフォルト引数） | `11_functions.py` | `12_functions_review.py` |

復習（`*_review.py`）は、似たテーマを**全文打ち込み**しつつ、参照ビューでは要点（演算子・
キーワードなど）が `[n]` に隠れる。思い出して打つ軽い retrieval。各ファイルに
`@hidemode reference` を指定済みなので、設定の切り替えは不要。
